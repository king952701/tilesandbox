# TILESANDBOX 系统 GDD（三支柱）

三支柱：**P1 挖掘建造（骨架）** · **P2 生存探索（压力）** · **P3 农场经营（经营）**。
数值全部数据驱动，放 `assets/data/*.json`；`gameplay/**` 只做公式，不写死常量，不用帧计数（一律 delta time）。

## 2. 挖掘与工具（P1）

**硬度分层**

| 层 | 材质 | H |
|---|---|---|
| T1 | 土、沙、草 | 0.5 |
| T2 | 软石、木材、黏土 | 2.0 |
| T3 | 硬石、砖 | 4.0 |
| T4 | 矿石、宝石 | 8.0 |
| — | 基岩 | ∞ 不可挖 |

**工具**：`{徒手 power 0.5 / speed 1.0}`、`木镐 1.5 / 1.2`、`石镐 2.5 / 1.5`、`铁镐 4.5 / 1.8`、
`钢镐 6.5 / 2.2`、`钻镐 10.0 / 3.0`。

**公式**

```
pf        = clamp(tool.power / tile.H, 0.25, 2.5)
dig_time  = tile.H / (tool.speed * pf)           // 秒，delta time 累加
tool.tier + 1 < tile.tier  → 不可挖，提示"需要 <X> 镐"
```

> 门控口径（已裁决）：工具可挖**自己这一级和再高一级**，所以徒手（tier 0）挖得动土/沙（tier 1），
> 木镐（tier 1）挖得动石头（tier 2）；铁矿（tier 4）必须石镐以上。

**示例（秒，由 `tests/run.js` 实测断言）**：

| 组合 | 时长 |
|---|---|
| 泥土 / 徒手 | 0.50 |
| 泥土 / 木镐 | 0.17 |
| 石头 / 木镐 | 2.22 |
| 石头 / 石镐 | 1.07 |
| 石头 / 铁镐 | 0.49 |
| 铁矿 / 铁镐 | 7.90 |
| 铁矿 / 钢镐 | 4.48 |
| 铁矿 / 钻镐 | 2.13 |

> 矿石偏慢（7.9 s）是 M1 已知的不平衡，故意不动数值：等 M2 有真实掉落与工具曲线后统一调
> `power`，目标铁矿/铁镐 ≈ 2 s。改动属数值平衡，会在 M2 记录。

**掉落**：100% 掉自身方块 ×1；矿石层额外 20% 掉同矿 ×1；硬度高于工具不掉；草/花掉种子 1–2（P3 预留）。

**边界用例**：目标格是基岩 → 不可挖且不掉；目标格为空/背景墙 → 先挖墙再挖地；背包满 → 掉落物落地成实体
（M1 简化为直接丢弃并提示"背包已满"）；挖掘中被击退 → 进度清零（M2）。

## 3. 合成（P1/P3）

**台面 4 级**：T0 徒手 → T1 工作台 → T2 熔炉/灶台 → T3 铁砧（T4 磨坊/织布机属 P3）。

**配方文件** `assets/data/recipes.json`：`{id, station, inputs:[{item,count}], outputs:[{item,count}],
time_sec, unlock:{type:"default"|"flag"|"station"|"item_seen", value}, sort}`，物品查 `items.json`。

**M1 三条**：木镐 `T0: wood×10 → 木镐×1 (0.5s)`；火把 `T0: wood×2 + fiber×1 → 火把×4 (0.25s)`；
工作台 `T0: wood×20 → 工作台×1 (1.0s)`。

**规则**：T1+ 台面需站在 3 tile 内；`time_sec` 为配方常量，用 delta time 累加；材料不足时按钮禁用且不扣料。

## 4. 生存（P2，M2）

- **昼夜**：1 游戏日 = 20 真实分钟 = 24 游戏小时 → **1 游戏小时 = 50 秒**；昼 06:00–18:00（10 min），
  夜 18:00–06:00（10 min）；黎明/黄昏过渡各 30 游戏分钟（25 秒）。
- **饥饿**：0–100；消耗 静止 `2.0` / 行走 `3.0` / 挖掘战斗 `5.0`（每游戏小时）；>80 时 `+1 HP/5s`；
  =0 时 `-1 HP/s`、移速 −30%、挖掘速度 −50%。面包 +40，浆果 +10。
- **刷怪**：仅夜晚且目标格 `light < 0.25`；距玩家 **24–64 tile**（<24 不刷、>64 不刷）；需实心地面 +
  上方 2 格空；间隔 `2.0s ±0.5`；密度上限 地表 8 / 洞穴 12 / 同屏活动实体 64；亮度 ≥0.25 或玩家光源
  3 tile 内抑制刷新。
- **战斗初值**：玩家 HP 100；木剑 10 / 铁剑 25；史莱姆 20 HP / 6 伤，洞穴蝙蝠 30/10，僵尸 60/14；
  `dmg = max(1, atk - def)`；`knockback = dmg * 0.8`。
- **死亡**：原地掉落背包，10 秒后出生点复活，HP 回 50%、饥饿重置 50，掉落 50% 货币（P3）。

## 5. 农场经营（P3，M3）

- **作物 4 阶段**：种子 → 幼苗（6 游戏小时）→ 成长（10）→ 成熟（10），共 26 游戏小时 ≈ 21.7 真实分钟。
- **速率**：`rate = base × light × water × season`；光照 <0.3 时 ×0.5（火把可补光）；相邻 8 格含水 ×1.25；
  当季 ×1.0、非当季 ×0（停滞不枯死）；4 季，每季 7 游戏天。
- **养殖**：从动物所在格 4 向 flood-fill，200 格内未触达开放边界 = 有效围栏；需 ≥1 食槽且 2–8 只
  （>8 拥挤产出 −50%）。鸡 6 游戏小时产 1 蛋，羊 12 小时产 1 羊毛。
- **闭环 2 条**：① 小麦 →（磨坊）面粉 →（灶台）面包 +40 饥饿 → 支撑长时洞穴探索 → 更多铁矿 → 铁镐 →
  挖掘提速 ×2.4；② 围栏养鸡 → 蛋/羊毛 → 布料 → 背包 +8 格 → 单次下洞携带量 +40%。

## 6. 光照（P1，M1）

- **阳光**：按列从地表向下衰减，遇实心格衰减加剧（Terraria 式 BFS）。
- **点光源**：火把半径 6 tile，中心亮度 1.0，线性衰减。
- **lightmap**：每格 1 像素，chunk 级脏区 BFS，10 Hz 更新（移动端 5 Hz）。
- **昼夜三档**：`{skyColor, ambient, sunAngle, lightRGB}` 三元组按时间线性插值；白天 lightmap 全 1
  （跳过光照管线，仅 1 次 tint）；黄昏走完整管线 + 暖色 multiply；夜晚走完整管线 + 冷色 tint + 点光源。

## 7. M1 垂直切片范围与验收

**只做**：1 个 biome 的世界切片 + 按屏 chunk 流式加载；tile 表与 4 层硬度；徒手/木镐挖掘 + 掉落入包；
放置（土/石/木材/火把）；移动、跳跃、tile 碰撞；9 格热栏 + 3 条手工合成；20 分钟昼夜循环（光照与配色）；
火把光源与亮度扩散；单存档槽持久化。
