# TILESANDBOX 美术圣经

## 0. 总原则：零外部素材

**仓库内不放任何第三方图片、字体、音频。** 所有视觉在启动时由 Canvas 程序化绘制成图集。
这既是版权约束（不引入未授权素材），也让首包压到 < 5 MB。

## 1. 画风

- **像素风 2.5D**：16 px 基准 tile，侧视；立体感来自"分层视差 + 顶部高光 + 底部阴影 + 光照"，
  不是真 3D。
- **调色板**：每个 biome 一组 5 色（亮面 / 主色 / 暗面 / 描边 / 点缀）。M1 只有「草原」biome。

| 角色 | 色值（草原 biome） |
|---|---|
| 天空（昼） | `#7EC0EE` → `#B8E0F0` 渐变 |
| 天空（黄昏） | `#F0956B` → `#F7C59F` |
| 天空（夜） | `#0B1020` → `#1B2440` |
| 草地亮面 / 主色 / 暗面 | `#7CC24A` / `#4E9A34` / `#2F6B22` |
| 泥土 | `#C08A5A` / `#8A5A34` / `#5C3A22` |
| 石头 | `#B9BEC4` / `#7E848C` / `#4E545C` |
| 木材 | `#D2A46A` / `#96643A` / `#5E3C22` |
| 煤矿 / 铁矿 / 金矿 / 宝石 | `#2E2E34` / `#C98A5E` / `#E8C34A` / `#5AD2E0` |
| 描边 | `#1A1410`（1 px，只在材质交界处） |

## 2. Tile 图集与 autotiling

- **基准**：16 px，图集 **2048²**（移动端安全上限，16 px 下可放 128×128 = 16384 张）。
- **地表材质（草/沙/雪/土交界）用 47 变体 blob**：8 邻域位定义 `N=1, E=2, S=4, W=8, NE=16, SE=32,
  SW=64, NW=128`，256 组合 → 16 基础 + 31 对角过渡 = 47 张。16 变体 4-bit 在 16 px 下会出现对角空洞，不用。
- **墙体、矿脉、管道用 4-bit 16 变体**（只认 N/E/S/W）。
- **纯填充内部**：4 张随机变体，按 `hash(tx,ty) & 3` 选，消除重复感。
- **结论**：每种地表材质 47+4 = 51 张；每种墙/矿脉 16 张。M1 的 4 种地表 ≈ 204 张，全部程序化派生。
- **查表**：`Uint8Array(256)` 的 bitmask → 变体索引，O(1)，查表期零分配。
- 同一 biome 的材质必须合并进同一张图集，避免同屏跨图集导致的源切换。

## 3. 视差背景（程序化）

| 层 | 视差 | 画法 |
|---|---|---|
| 天空 | — | CSS linear-gradient（三档按时间插值） |
| 远山 | 0.15 | 折线剪影，2 层噪声，暗面 `#3A4A62` |
| 云 | 0.25 | 圆角矩形团簇，白 → 暖白（黄昏）/ 冷灰（夜） |
| 中景树线 | 0.5 | 简化树剪影 `#2F4A34` |
| 前景草叶 | 1.2 | 少量摆动草叶（sin 摆动，幅度 ≤ 2 px） |

每层预渲染成 1024×512 的离屏 strip，横向 wrap 平铺，运行时只做 3–6 次 drawImage。

## 4. 实体与 UI

- **玩家**：24×32 px 侧视小人（头/身/腿三块 + 描边），行走 4 帧（腿摆动），挖掘 3 帧（手臂挥动）。
- **掉落物**：8×8 px，带 1 px 高光，上下浮动 ±2 px。
- **HUD**：DOM + CSS。热栏 9 格（56×56 dp），血条/饥饿条左上，时间钟右上，合成面板居中弹层。
  字体用系统 sans-serif（不引入字体文件）。
- **图标**：不用图标字体，用 Canvas 画的小色块 + 描边（M1）；后续可换成程序化 16 px 图标。

## 5. 光照视觉

- lightmap 每格 1 像素，绘制时放大 16×（双线性）得到平滑渐变。
- 点光源用**预渲染的径向渐变精灵**（64/128/256 px 三档，缓存复用），禁止每帧 `createRadialGradient`。
- 夜晚叠加冷色 `multiply`，黄昏叠加暖色；白天只有 1 次全屏 tint。

## 6. 移动端降级

- DPR 强制 ≤ 2；只支持整数 zoom（1/2），`imageSmoothingEnabled = false`，否则 16 px tile 会糊。
- lightmap 更新降到 5 Hz；点光源只保留玩家手持 + 最近 8 个；去掉径向柔光改硬边 tile 光；昼夜 tint 保留。
- 前景草叶与云在移动端去掉摆动（省 per-frame 计算）。
