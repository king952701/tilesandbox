## 多人联机：当前做不到，原因与出路

聊天里"其他玩家可以查看"需要**服务端**转发消息与存放媒体。当前交付是纯客户端：
GitHub Pages 是静态站，Cordova 包里也只有 WebView，**两部手机之间没有任何通道**。

`MessageBus` 已经按"可插传输层"设计，接上即用：

```js
bus.attachRemote({
  async send(msg) { ws.send(JSON.stringify(msg)); },        // 媒体需先上传到对象存储换成 URL
  onMessage(cb) { ws.onmessage = (e) => cb(JSON.parse(e.data)); },
});
```

要真正联机，三选一（都需要你点头，我不会擅自接第三方）：

| 方案 | 代价 | 备注 |
|---|---|---|
| 自建 Node WebSocket 服务器 | 需要一台公网可达的主机（本机 github.com 443 不通，家里宽带需端口映射） | 完全自控，无第三方依赖 |
| 第三方 BaaS（Firebase / Supabase 等） | 需要注册账号与密钥，且属外部依赖 | 与"不引入未授权第三方"的长期约束冲突，必须先确认 |
| 局域网同 Wi-Fi 直连 | 只能同一网络下玩，且仍需一台机器跑信令 | 成本最低，可先做 |
